```npm
npm install @ingredient-icons/core
```

The package is plain JavaScript with no native code: it works in Expo Go and bare React Native without a rebuild. Metro imports `catalog.json` like any JSON file, for the fallback in [Ids and fallback](/docs/guides/ids-and-fallback).

## With Expo Image

[`expo-image`](https://docs.expo.dev/versions/latest/sdk/image/) decodes WebP on both platforms and caches files on disk, so an icon downloads once.

```tsx title="components/IngredientIcon.tsx"
import { Image } from "expo-image"
import { iconUrl } from "@ingredient-icons/core"
import { iconFor } from "@/lib/ingredient-icon"

export function IngredientIcon({ id, size = 40 }: { id: string; size?: number }) {
  // Its own icon, else its nearest ancestor's, else the generic icon: never undefined.
  const uri = iconUrl(iconFor(id), { size: size <= 42 ? 128 : 256 })!
  return (
    <Image
      source={{ uri }}
      style={{ width: size, height: size }}
      cachePolicy="disk"
      transition={120}
      accessible={false}
    />
  )
}
```

`accessible={false}` hides the icon from VoiceOver and TalkBack when the ingredient's name is next to it.

## With the built-in Image

```tsx
import { Image } from "react-native"
import { iconUrl } from "@ingredient-icons/core"

<Image source={{ uri: iconUrl("shallot") }} style={{ width: 40, height: 40 }} />
```

## Offline

To ship icons inside the app, copy the ones you need from `node_modules/@ingredient-icons/core/icons/webp/` into your assets and `require` them. With hundreds of icons, a CDN and a disk cache is usually the better trade.
