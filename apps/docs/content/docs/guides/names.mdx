`catalog.json` names every entry, whether it has an icon or not: an ingredient that borrows its parent's icon still has its own name. French and English names are reviewed by Marmalade. Spanish, Italian, German and Portuguese come from Wikidata, where it has them.

<NameCoverage />

Each language has a `name` and a list of `synonyms`:

```json title="catalog.json (excerpt)"
"shallot": {
  "parent": "onion",
  "family": "vegetables",
  "names": {
    "fr": { "name": "échalote", "synonyms": [] },
    "en": { "name": "shallot", "synonyms": [] },
    "it": { "name": "scalogno", "synonyms": [] },
    "de": { "name": "Schalotte", "synonyms": ["Schalotten"] }
  }
}
```

## Reading a name

```ts title="ingredient-names.ts"
import catalog from "@ingredient-icons/core/catalog.json"

type Language = "fr" | "en" | "es" | "it" | "de" | "pt"
type Names = Partial<Record<string, { name?: string; synonyms: string[] }>>
const entries: Record<string, { names: Names }> = catalog.entries

/** An ingredient's name in a language, else its English name. */
export function nameOf(id: string, language: Language = "en"): string | undefined {
  const names = entries[id]?.names
  return names?.[language]?.name ?? names?.en?.name
}
```

```ts
nameOf("shallot") // "shallot"
nameOf("shallot", "fr") // "échalote"
nameOf("shallot", "de") // "Schalotte"
nameOf("shallot", "es") // "shallot"
nameOf("creme-fraiche", "fr") // "crème fraîche"
```

Shallot has no Spanish name in the catalog yet, hence the English one.

## Name the ingredient, not the icon

For an ingredient that falls back to an ancestor's icon, use the ingredient's own name: `extra-virgin-olive-oil` shows the olive oil icon, but its alt text, if it needs one, is "extra virgin olive oil".

Family names come from Wikidata labels and can read oddly (`eggs` is "egg as food" in English). Your interface probably names families its own way.

The generic icon is not in the catalog. Name it yourself, "Ingredient" for example.

## Searching by synonyms

Synonyms are spellings and other names people type: "EVOO" for extra virgin olive oil, "Schalotten" for shallots. Search them with the names to map free text to a catalog id (`entries` as in `ingredient-names.ts` above):

```ts
const matches = Object.entries(entries).filter(([, entry]) =>
  Object.values(entry.names).some((names) =>
    [names?.name, ...(names?.synonyms ?? [])].some((text) => text?.toLowerCase() === query.toLowerCase()),
  ),
)
```

Your recipe data most likely has its own names for ingredients already: use those in the interface, and the catalog's for search, alt text and the languages you don't cover.
