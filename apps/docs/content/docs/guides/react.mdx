The package has no React dependency: `iconUrl` returns a string you put in an `<img>`. A small component of your own keeps sizes and the fallback in one place. It uses `iconFor` from [Ids and fallback](/docs/guides/ids-and-fallback).

## A typed component

```tsx title="components/ingredient-icon.tsx"
import { iconUrl, type IconSize } from "@ingredient-icons/core"
import { iconFor } from "@/lib/ingredient-icon"

interface Props {
  /** Catalog id: "shallot" */
  id: string
  /** Display size in CSS pixels. */
  size?: number
}

// The smallest file that stays sharp on a 2× screen.
function fileSize(size: number): IconSize {
  if (size <= 32) return 64
  if (size <= 64) return 128
  return 256
}

export function IngredientIcon({ id, size = 40 }: Props) {
  // Its own icon, else its nearest ancestor's, else the generic icon: never undefined.
  const src = iconUrl(iconFor(id), { size: fileSize(size) })!
  return <img src={src} alt="" width={size} height={size} loading="lazy" decoding="async" />
}
```

```tsx
<IngredientIcon id="cherry-tomato" size={48} />
<IngredientIcon id="brioche-bun" size={48} />
```

## Choosing a size

| Displayed at | File size |
| --- | --- |
| up to 32 px | `64` |
| up to 64 px | `128` (the default) |
| larger | `256` |

128 px covers a 40 pt icon on a 3× phone screen. See [Sizes and formats](/docs/reference/sizes).

## Alt text

Leave `alt` empty when the ingredient's name is written next to the icon, which is the case in an ingredient list. When the icon stands alone, name the ingredient (not the icon it borrows), with `nameOf` from [Names](/docs/guides/names):

```tsx
import { nameOf } from "@/lib/ingredient-names"

<img src={iconUrl(iconFor("shallot"))} alt={nameOf("shallot", "fr") ?? ""} />
```

## Rendering on the server

`iconFor` imports `catalog.json`, under 100 KB gzipped. In a framework with server rendering, call it on the server and only send URLs to the browser. See [Next.js](/docs/guides/nextjs).
