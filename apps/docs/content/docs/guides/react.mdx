The package has no React dependency: `iconUrl` returns a string you put in an `<img>`. A small component of your own keeps sizes and placeholders in one place.

## A typed component

```tsx title="components/ingredient-icon.tsx"
import { iconUrl, type IconSize } from "@ingredient-icons/core"

interface Props {
  /** Open Food Facts id: "en:shallot" */
  id: string
  /** Display size in CSS pixels. */
  size?: number
}

// The smallest file that stays sharp on a 2× screen.
function fileSize(size: number): IconSize {
  if (size <= 32) return 64
  if (size <= 64) return 128
  return 256
}

export function IngredientIcon({ id, size = 40 }: Props) {
  const src = iconUrl(id, { size: fileSize(size) })
  if (!src) return <span style={{ width: size, height: size }} aria-hidden />
  return <img src={src} alt="" width={size} height={size} loading="lazy" decoding="async" />
}
```

```tsx
<IngredientIcon id="en:cherry-tomato" size={48} />
```

## Choosing a size

| Displayed at | File size |
| --- | --- |
| up to 32 px | `64` |
| up to 64 px | `128` (the default) |
| larger | `256` |

128 px covers a 40 pt icon on a 3× phone screen. See [Sizes and formats](/docs/reference/sizes).

## Alt text

Leave `alt` empty when the ingredient's name is written next to the icon, which is the case in an ingredient list. When the icon stands alone, name it:

```tsx
import { iconName, findIcon } from "@ingredient-icons/core"

const icon = findIcon("en:shallot")
<img src={iconUrl("en:shallot")} alt={icon && iconName(icon.id)} />
```

## Rendering on the server

The taxonomy data is about 57 KB gzipped. In a framework with server rendering, call `iconUrl` on the server and only send URLs to the browser. See [Next.js](/docs/guides/nextjs).
