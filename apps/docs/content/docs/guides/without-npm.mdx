The icons are plain files in the [GitHub repository](https://github.com/EBf-Studio/ingredient-icons), with two JSON files that describe them. Packages for native platforms will follow under the `@ingredient-icons` scope.

PNG is the canonical format, and the only one in 512 px. WebP is the same image, smaller, for the web and React Native. `manifest.json` lists the ids that have an icon, `catalog.json` the ingredient catalog: see [the file formats](/docs/reference/files).

```sh
git clone --depth 1 https://github.com/EBf-Studio/ingredient-icons.git
```

The repository grows with every batch of icons: `--depth 1` skips the history.

## Straight from a CDN

jsDelivr serves any file of the repository:

```txt
https://cdn.jsdelivr.net/gh/EBf-Studio/ingredient-icons@main/icons/png/256/shallot.png
```

Replace `main` with a commit hash to pin the files.

## Finding an icon

Look the id up in `manifest.json`. When it has none, follow `parent` in `catalog.json` and take the first ancestor that has one: the ingredient's family comes last. When nothing on the way has an icon, show the generic one.

<Tabs items={["Python", "Swift", "Kotlin"]}>
<Tab value="Python">

```python title="icons.py"
import json

icons = set(json.load(open("manifest.json"))["icons"])
entries = json.load(open("catalog.json"))["entries"]

def icon_for(id: str) -> str:
    seen, at = set(), id
    while at is not None and at not in seen:
        if at in icons:
            return at
        seen.add(at)
        at = entries.get(at, {}).get("parent")
    return "generic"

icon_for("extra-virgin-olive-oil")  # "olive-oil"
```

<Tab value="Swift">

```swift title="IngredientIcons.swift"
struct Manifest: Decodable { let icons: Set<String> }
struct Catalog: Decodable { let entries: [String: Entry]; struct Entry: Decodable { let parent: String? } }

func iconFor(_ id: String, manifest: Manifest, catalog: Catalog) -> String {
    var at: String? = id
    var seen = Set<String>()
    while let current = at, seen.insert(current).inserted {
        if manifest.icons.contains(current) { return current }
        at = catalog.entries[current]?.parent
    }
    return "generic"
}
```

<Tab value="Kotlin">

```kotlin title="IngredientIcons.kt"
fun iconFor(id: String, icons: Set<String>, parents: Map<String, String>): String {
    val seen = mutableSetOf<String>()
    var at: String? = id
    while (at != null && seen.add(at)) {
        if (at in icons) return at
        at = parents[at]
    }
    return "generic"
}
```

The id goes into `manifest.json`'s `path` template: `icons/{format}/{size}/{id}.{format}`. The generic icon, a cluster of fresh ingredients, has the id `generic` (`icons/png/128/generic.png`).
