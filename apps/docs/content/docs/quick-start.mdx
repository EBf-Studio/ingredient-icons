<Steps>

<Step>

### Install the package

```npm
npm install @ingredient-icons/core
```

</Step>

<Step>

### Get an icon URL

Pass a catalog id to `iconUrl`. You get a URL to a 128 px WebP on jsDelivr.

```ts
import { iconUrl } from "@ingredient-icons/core"

iconUrl("shallot")
// https://cdn.jsdelivr.net/npm/@ingredient-icons/core@<version>/icons/webp/128/shallot.webp
```

Ids are English names in kebab-case. The [gallery](/icons) shows the id of every icon, and `catalog.json` lists every ingredient the catalog knows.

</Step>

<Step>

### Fill the gaps with the catalog

`iconUrl` only knows an id's own icon: for an ingredient without one, it returns `undefined`.

```ts
iconUrl("extra-virgin-olive-oil") // undefined
```

The catalog knows that extra virgin olive oil is an olive oil. Copy this helper: it walks up the parents in `catalog.json` and returns the first id that has an icon, the ingredient's family last, and the generic icon when nothing on the way has one.

```ts title="ingredient-icon.ts"
import { GENERIC_ID, iconPath, type CatalogEntry } from "@ingredient-icons/core"
import catalog from "@ingredient-icons/core/catalog.json"

const entries: Record<string, CatalogEntry> = catalog.entries

/** The id whose icon an ingredient shows: its own, its nearest ancestor's (its family's last), or the generic icon. */
export function iconFor(id: string): string {
  const seen = new Set<string>()
  for (let at: string | undefined = id; at !== undefined && !seen.has(at); at = entries[at]?.parent) {
    if (iconPath(at)) return at
    seen.add(at)
  }
  return GENERIC_ID
}
```

<Resolves id="extra-virgin-olive-oil" />

```ts
import { iconUrl } from "@ingredient-icons/core"
import { iconFor } from "./ingredient-icon"

iconFor("extra-virgin-olive-oil") // "olive-oil"
iconFor("unicorn-steak") // "generic"
iconUrl(iconFor("unicorn-steak")) // …/icons/webp/128/generic.webp
```

`GENERIC_ID` (`"generic"`) is the generic icon, a cluster of fresh ingredients, for an id the catalog doesn't know. Since it ships with the others, `iconUrl(iconFor(id))` always returns a URL.

</Step>

<Step>

### Render it

The URL goes wherever an image goes.

```tsx title="Ingredient.tsx"
import { iconUrl } from "@ingredient-icons/core"
import { iconFor } from "./ingredient-icon"

export function Ingredient({ id, name }: { id: string; name: string }) {
  return (
    <li>
      <img src={iconUrl(iconFor(id))} alt="" width={40} height={40} />
      {name}
    </li>
  )
}
```

`alt` is empty because the name is written next to the icon: a screen reader would say it twice.

</Step>
