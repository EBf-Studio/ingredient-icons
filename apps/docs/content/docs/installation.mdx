```npm
npm install @ingredient-icons/core
```

The package is [on npm](https://www.npmjs.com/package/@ingredient-icons/core) and works in browsers, Node, Bun, Deno and React Native. It is ESM only and ships its own TypeScript types.

## What is inside

- `dist/` holds the functions and the list of ids that have an icon. A few kilobytes.
- `icons/webp/{size}/` holds the image files, one per icon and size, named after their id, for when you [serve them yourself](/docs/guides/self-hosting).
- `catalog.json` is the ingredient catalog: every ingredient and family, its parent and its names. Import it as `@ingredient-icons/core/catalog.json` for the [fallback](/docs/guides/ids-and-fallback) and the [names](/docs/guides/names).

You don't have to bundle the images. By default the URLs point at the [jsDelivr](https://www.jsdelivr.com) CDN, pinned to the version you installed.

## Bundle size

The functions weigh almost nothing. `catalog.json` is the heavy part, a few hundred kilobytes (under 100 KB gzipped), and it only enters your bundle if you import it. On the web, walk the catalog on the server when you can (a Server Component, an API route, your build step) and send only the URLs to the browser. In a mobile app it is a small part of the bundle.

In plain Node, import the JSON with an import attribute: `import catalog from "@ingredient-icons/core/catalog.json" with { type: "json" }`. Bundlers and Bun don't need it.

<Callout title="No npm?">
  The icons are plain files in a Git repository, with two JSON files. See [Without npm](/docs/guides/without-npm) for Swift, Kotlin, Python or anything else.
</Callout>
