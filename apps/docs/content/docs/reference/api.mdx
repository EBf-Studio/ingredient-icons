The functions only know an id's own icon: there is no fallback inside the package. To show an ancestor's icon for an ingredient that has none, walk up `catalog.json` as in [Ids and fallback](/docs/guides/ids-and-fallback).

## iconUrl

```ts
function iconUrl(id: string, options?: { size?: IconSize; baseUrl?: string }): string | undefined
```

URL of the id's own WebP file. `undefined` when the id has no icon of its own.

<TypeTable
  type={{
    size: { type: 'IconSize', typeDescription: '64 | 128 | 256', default: '128', description: 'Width and height of the file, in pixels.' },
    baseUrl: { type: 'string', default: 'CDN_URL', description: 'Folder that contains the package\'s icons/ folder. See Self-hosting.' },
  }}
/>

```ts
iconUrl("shallot", { size: 256 })
// https://cdn.jsdelivr.net/npm/@ingredient-icons/core@<version>/icons/webp/256/shallot.webp

iconUrl("extra-virgin-olive-oil") // undefined: no icon of its own
iconUrl(GENERIC_ID) // …/icons/webp/128/generic.webp
```

## iconPath

```ts
function iconPath(id: string, size?: IconSize): string | undefined
```

Path of the id's own icon inside the package, or `undefined` when it has none. `size` defaults to `128`.

```ts
iconPath("shallot", 64) // "icons/webp/64/shallot.webp"
iconPath("cheeses") // "icons/webp/128/cheeses.webp"
```

## catalog.json

```ts
import catalog from "@ingredient-icons/core/catalog.json"

catalog.entries["shallot"].parent // "onion"
catalog.entries["shallot"].family // "vegetables"
catalog.entries["shallot"].names.fr.name // "échalote"
```

The ingredient catalog the ids come from: every family and catalog ingredient, with its parent, its family and its names in six languages. See [Files](/docs/reference/files) for its format, and [Names](/docs/guides/names).

## Types

```ts
type IconSize = 64 | 128 | 256
```

```ts
interface Catalog {
  release: string // CATALOG_RELEASE
  license: "CC0-1.0"
  entries: Record<string, CatalogEntry>
}

interface CatalogEntry {
  parent?: string // none for a family
  family?: string // none for a family
  names: Partial<Record<string, CatalogNames>> // fr, en, es, it, de, pt
}

interface CatalogNames {
  name?: string
  synonyms: string[]
}
```

The shape of `catalog.json`. A JSON import is typed with its exact keys, so give it this type to index it with any string: `const catalog: Catalog = snapshot as Catalog`.
