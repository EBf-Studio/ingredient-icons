## findIcon

```ts
function findIcon(id: string): Icon | undefined
```

The icon of an Open Food Facts ingredient id, or of its closest ancestor in the taxonomy when it has none of its own. `undefined` when no ancestor within six levels has one. See [Ids and fallback](/docs/guides/ids-and-fallback).

```ts
findIcon("en:cherry-tomato") // { id: "en:tomato", file: "en_tomato", exact: false }
```

## iconUrl

```ts
function iconUrl(id: string, options?: { size?: IconSize; baseUrl?: string }): string | undefined
```

URL of the icon's WebP file, after fallback. `undefined` when `findIcon` finds nothing.

<TypeTable
  type={{
    size: { type: 'IconSize', typeDescription: '64 | 128 | 256', default: '128', description: 'Width and height of the file, in pixels.' },
    baseUrl: { type: 'string', default: 'CDN_URL', description: 'Folder that contains the package\'s icons/ folder. See Self-hosting.' },
  }}
/>

```ts
iconUrl("en:shallot", { size: 256 })
// https://cdn.jsdelivr.net/npm/@ingredient-icons/core@<version>/icons/webp/256/en_shallot.webp
```

## iconPath

```ts
function iconPath(id: string, size?: IconSize): string | undefined
```

Path of the icon inside the package, after fallback. `size` defaults to `128`.

```ts
iconPath("en:shallot", 64) // "icons/webp/64/en_shallot.webp"
```

## iconName

```ts
function iconName(id: string, locale?: "en" | "fr"): string | undefined
```

Name of an id that has its own icon, from the Open Food Facts taxonomy. `locale` defaults to `"en"`. No fallback: `undefined` for ids without an icon. See [Names](/docs/guides/names).

```ts
iconName("en:shallot", "fr") // "échalote"
```
